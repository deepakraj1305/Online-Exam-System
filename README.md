# ExamPro — Cloud Online Examination System

A professional, responsive front-end for a Cloud Computing Online Examination System.

## Features

- Modern professional dashboard UI
- Dark sidebar navigation
- Gradient hero section and visual exam illustration
- Exam statistics cards
- Student profile and candidate personalization
- Python Basics assessment
- 5-minute countdown timer
- Live question progress indicator
- Automatic submission when time expires
- Score/result dashboard
- Responsive design for desktop, tablet and mobile
- No external JavaScript framework required

## Run Locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## GitHub / Vercel

This is a static front-end project, so it can be deployed directly to GitHub Pages, Vercel, Netlify, or any static hosting service.

# 🎓 Online Exam System

A modern and responsive **Cloud-Based Online Examination System** designed to provide students with a professional platform for taking online assessments, tracking exam progress, and viewing results.

## 🚀 Live Demo

🌐 **Live Website:** https://online-exam-system-id8s.vercel.app/

---

## 📌 Project Overview

The **Online Exam System** is a web-based examination platform that allows students to attend online tests through a clean and professional dashboard.

The system provides an interactive examination interface with:

* Student login
* Professional dashboard
* Online examination
* Countdown timer
* Question navigation
* Answer selection
* Automatic score calculation
* Result display
* Responsive design
* Cloud deployment

The project is designed with a modern dashboard interface suitable for a **Cloud Computing / Web Technology academic project**.

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd Online-Exam-System
```

### 3. Open in VS Code

```bash
code .
```

### 4. Run the project

Use **Live Server** in VS Code.

Right-click:

```text
index.html
```

and select:

```text
Open with Live Server
```

The application will open in your browser.
